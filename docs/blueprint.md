# **App Name**: NovaPOS

## Core Features:

- Product Catalog Management: Admins can add, edit, or remove products, including details like name, price, stock, and category, stored in a backend database.
- Intelligent Product Description Generator: A generative AI tool that assists store owners by suggesting concise and appealing product descriptions based on product name and category.
- Intuitive Sales Interface: A user-friendly interface for cashiers to quickly add items to the cart, adjust quantities, and apply discounts.
- Order Processing & Payment: Calculate order totals, handle multiple payment types (cash, card-dummy), and finalize transactions.
- Basic Sales Reporting: View daily transaction history and basic sales summaries for operational insights, pulled from the database.
- Secure Staff Login: Authentication system allowing authorized staff to access the POS functionalities.

## Style Guidelines:

- Primary color: A clear, professional blue (#2D6CDB) to convey trust and efficiency, serving as the main brand accent and for interactive elements.
- Background color: A very light, almost imperceptible blue-gray (#EBF0F6) for a clean, open, and modern workspace that promotes focus.
- Accent color: A vibrant purple (#763DF5) used for highlighting key actions, notifications, and calls-to-action to create a distinct, modern feel.
- Primary typeface: 'Inter' (sans-serif) for all text elements, chosen for its excellent readability, neutrality, and modern, machined aesthetic, ensuring clarity in all transactional displays.
- Use a consistent set of simple, line-based icons for navigation and action buttons to maintain a clean and contemporary visual language.
- Implement a modular and adaptive layout that is clean, spacious, and easily scannable, optimizing product display and transaction areas for efficient user interaction on various screen sizes.
- Incorporate subtle and functional animations for user feedback on actions, such as item additions to the cart or successful transactions, to enhance usability without being distracting.
